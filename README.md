# Freedom Counter

A simple, private habit counter to help break addictions, one day at a time.

## Features
- Track any number of things you're quitting, each with a live days / hours / minutes / seconds counter
- Milestones (1 day → 2 years) with a progress bar and celebration when you hit one
- "I resisted an urge" button to count your victories
- "I slipped" restart that keeps your best streak and logs what triggered it, so you can learn from it
- Optional money-saved tracker
- Your personal "why" shown on each card
- A Bible verse of the day for encouragement
- Export / import a backup file
- Everything is stored only in your browser (localStorage), with no account and no server

## Use it
Open `index.html` in any browser. To use it on your phone, turn on GitHub Pages
(Settings → Pages → Deploy from branch) and open the link, then "Add to Home Screen".
